# algorithm

프로그래머스 · 백준 · SWEA 풀이 기록. 주 언어는 Java입니다.

**[📊 학습 로그 대시보드](https://trossyou.github.io/algorithm/)**

풀이 코드는 이 저장소에, 접근 방식과 막힌 지점은 대시보드에 남깁니다.

---

## 기록 방식

코드만 쌓아두면 나중에 다시 봐도 *왜* 그렇게 풀었는지가 남지 않습니다.
그래서 두 가지를 분리해 관리합니다.

| | 무엇을 | 어떻게 |
|---|---|---|
| 저장소 | 제출한 코드 | [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub)이 정답 처리 시 자동 커밋 |
| 대시보드 | 접근 · 복잡도 · 막힌 지점 · 오답 원인 | 문제를 푼 당일 직접 기록 |

대시보드에서는 알고리즘 유형을 노드로 하는 그래프로 어떤 유형에 편중돼 있는지 보고,
혼자 풀지 못한 문제를 복습 대기 목록으로 관리합니다.
오답 원인을 `접근 못 떠올림 / 구현 실수 / 엣지케이스 / 시간초과 / 문제 이해` 다섯 가지로
분류해 반복되는 약점을 추적합니다.

같은 문제를 다시 풀면 새 항목을 만들지 않고 회차로 쌓습니다.
1회차에 답을 보고 푼 문제를 2회차에 다르게 풀어냈다면, 그 변화가 한자리에 남습니다.

## 구조

```
프로그래머스/{레벨}/{문제번호}. {제목}/{제목}.java

archive/     이전 폴더 규칙으로 정리했던 풀이
scripts/     보조 스크립트
index.html   학습 로그 대시보드 (단일 파일, 의존성 없음)
```

## 대시보드

외부 라이브러리 없이 HTML 파일 하나로 동작합니다.
힘 기반 그래프 레이아웃, 필터, 검색 모두 바닐라 JS로 구현했습니다.

- **유형 그래프** — 유형 노드를 중심으로 문제가 붙는 구조. 드래그 · 호버 · 클릭으로 탐색
- **복습 대기** — 힌트나 답을 보고 푼 문제를 오래 묵은 순으로 정렬
- **필터** — 유형 / 레벨 / 언어 / 풀이 방식 / 오답 원인
- 기록은 파일 안 `PROBLEMS` 배열에 담기며, 브라우저 저장소를 쓰지 않아 어느 기기에서 열어도 같습니다

## 커밋 규칙

BaekjoonHub의 자동 커밋과 구분하기 위해 직접 남기는 커밋에는 `log` 스코프를 씁니다.

```
docs(log): 0811 기록 3건 — 단어 변환, 연속 부분 수열 외 1건
feat(log): 언어 필터 추가
chore(repo): 이전 폴더 구조 정리
```
