내 GitHub 저장소 연결

스크립트 맨 위 REPO에 아이디와 저장소 이름을 한 번만 적어두면, 머리말에 저장소 링크가 생기고 각 문제마다 저장소에서 찾기 ↗ 버튼이 붙습니다. 문제 이름으로 코드 검색이 걸려서 백준허브 폴더 구조를 몰라도 됩니다.

codeUrl은 비워두세요. 백준허브 규칙(프로그래머스/{레벨}/{번호}. {제목}/{제목}.{확장자})으로 링크를 자동 조립합니다. 제목에 특수문자가 있어 경로가 어긋나면 저장소에서 찾기로 넘어가면 되고, 정확한 경로를 알면 codeUrl에 상대 경로나 전체 URL을 적어 덮어쓸 수 있습니다.
